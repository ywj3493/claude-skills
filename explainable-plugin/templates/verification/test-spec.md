## 개요

### 테스트 유형

| 유형 | 검증 대상 | 범위 |
|---|---|---|
| **단위** | 격리된 로직 | 함수·클래스 하나 |
| **통합** | 구성 요소 간 상호작용 | 여러 모듈 |
| **계약** | 인터페이스 계약 준수 | 요청·응답 스키마 |
| **E2E** | 사용자 여정 전체 | 사용자 행동부터 최종 결과까지 |

### 우선순위

| 등급 | 의미 |
|---|---|
| P0 | 실패하면 핵심 기능이 동작하지 않음 |
| P1 | 실패하면 주요 사용 사례가 손상됨 |
| P2 | 실패해도 우회 가능 |
