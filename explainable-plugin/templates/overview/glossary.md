# 용어집

한국어 문서에서 쓰는 용어와 코드에서 쓰는 영문 식별자의 대응표다.

**사용 규칙**

1. 문서를 쓰기 전에 이 표를 먼저 읽는다. 이미 있는 개념에 새 한국어 용어를
   지어내지 않는다.
2. 새 개념이 나오면 이 표에 추가한 뒤 문서에서 쓴다.
3. 코드 심볼 이름은 `영문 식별자` 열을 따른다. 문서에서만 쓰는 번역어를
   코드에 넣지 않는다.
4. 한 개념에 영문 식별자는 하나만 둔다. 코드에 여러 표기가 섞여 있으면
   `비고`에 기록하되 대표 식별자를 하나 정한다.
