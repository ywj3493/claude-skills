## 플로우 상세

<!--
플로우 하나당 한 섹션. 유저 스토리 하나에 대응하는 것이 보통이다.

`flowchart TD`로 그린다. 노드는 **사용자가 보는 화면이나 결정**이고,
간선은 **사용자 행동**이다. 서버 처리는 노드 하나로 뭉뚱그리고 그 안을
그리지 않는다.
-->

### UF-<도메인>-01: <플로우 이름>

| 항목 | 내용 |
|---|---|
| **관련 스토리** | US-NN |
| **주 액터** | |
| **사전 조건** | |
| **성공 기준** | |

```mermaid
flowchart TD
    START([주문 목록 화면]) --> PICK{주문 선택}
    PICK -->|주문 클릭| DETAIL[주문 상세 화면]
    DETAIL --> CANCEL{취소 가능?}
    CANCEL -->|가능| CONFIRM[취소 확인 대화상자]
    CANCEL -->|불가| DISABLED[취소 버튼 비활성 안내]
    CONFIRM -->|확인| PROCESSING[처리 중 표시]
    CONFIRM -->|취소| DETAIL
    PROCESSING --> RESULT{처리 결과}
    RESULT -->|성공| DONE([취소 완료 안내])
    RESULT -->|실패| ERROR[오류 안내와 재시도]
    ERROR --> CONFIRM
```
