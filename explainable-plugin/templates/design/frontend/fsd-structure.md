## 레이어 구성

<!--

근거 표이므로 열 구성을 바꾸지 않는다.

이 도메인이 사용하지 않는 레이어는 `실제 경로`를 `—`로 두고 `비고`에

## 세그먼트 구성

<!--
슬라이스 내부를 나누는 기술적 구획. 프로젝트가 실제로 쓰는 세그먼트만
남기고 나머지 행은 지운다.

`ui` / `model` / `api` / `lib` / `config`가 표준이지만, 프로젝트가 다른

-->

|---|---|---|---|
| ui | 화면에 그려지는 UI 단위 | | |
| model | 상태, 도출값, 비즈니스 로직 | | |
| api | 서버 통신과 응답 매핑 | | |
| lib | 슬라이스 전용 유틸 | | |
| config | 상수와 설정 | | |

## 의존 규칙

**기본 규칙**: 상위 레이어만 하위 레이어를 참조한다. 같은 레이어의 다른
슬라이스는 참조하지 않는다.

```text
app → pages → widgets → features → entities → shared
```
